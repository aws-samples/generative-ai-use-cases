## v5.6.0 (2026-11-27)

### 主な変更

- **チャット**: モデルの選択を入力欄のツールバーに移動、会話履歴を日付ごとに表示、選択したモデルと推論の設定をリロード後も保持、Markdown の表をスプレッドシートに貼り付けられる形でコピー、表のセル内の `<br>` で改行、チャットのモデルが今日の日付を把握、未送信のメッセージがあるままページを離れるときに確認するようになりました。回答が出力の上限で止まったときは「続きを出力」で続けられます。(#1788, #1781, #1787, #1782, #1786, #1783, #1784, #1863)
- **添付ファイル**: チャットの添付をブラウザから送らず、サーバーが S3 から読むようになりました。1 つのチャットで添付できる量の合計が約 4.5 MB から約 22 MB に増え、PDF は 1 つ 20 MB まで付けられます。(#1865)
- **システムプロンプト**: 新しいチャットで使うシステムプロンプトを各ユーザーが選べるようになり、システムプロンプトの編集はすぐに反映され、チャットのモデルにチャット画面で表示できる形式を伝えるようになりました。(#1848, #1844)
- **サイドバーと設定画面**: サイドバーをアイコン表示に折りたたんだり幅を変えたりでき、表示するユースケースを各ユーザーが選べるようになりました (お気に入り)。設定画面は「一般」「使用量」「アカウント」「システム」のタブに分かれ、「使用量」タブで自分のトークン使用量とコストを、「システム」タブでこのリリースノートを確認できます。(#1830, #1831)
- **音声**: 音声チャットで声と言語を選べるようになりました。音声認識の言語の自動判別の対象言語を設定画面で選べるようになり、音声チャットで Amazon Nova 2.5 Sonic を使えるようになりました。(#1727, #1779, #1726)
- **Agent Builder**: エージェントの定義を JSON ファイルで共有でき、ツールに AgentCore Web Search を追加できるようになりました。(#1689, #1673)
- **AgentCore**: コードインタープリターがチャットに添付したファイルを扱い、作成したファイルを返せるようになりました。回答の長さの上限が Converse の経路と同じになり、Claude Opus 4.7 以降の思考過程が表示されます。(#1767, #1768, #1772)
- **ブラウザ拡張機能**: 回答を Markdown で表示してコピーでき、コンテキストメニューからページ全体の本文を送れるようになりました。(#1852, #1854, #1853)
- **過去のチャットのファイル**: このリリースより前に保存した添付ファイル、画像、生成した動画、エージェントが出力したファイルは、管理者が移行するまで開けません (アップデート前の確認事項を参照)。図は画像として表示されます。
- **新しいモデル** (管理者が有効にすると使えます): Claude Opus 5、Claude Fable 5、Claude Opus 5.5、Claude Sonnet 5.5、Claude Haiku 5.5、Claude Fable 5.1 / 5.2、OpenAI GPT-6 / GPT-6.1 / GPT-6.2 Sol / GPT-6.2 Astra / GPT-5.4 / GPT-5.5 / GPT-5.6、Moonshot AI Kimi K3 / K3.1 / K2.5、Grok 4.6 / 4.7、GLM 5、DeepSeek V3.2、MiniMax M2.5、NVIDIA Nemotron 3 Super 120B、Qwen3 Coder Next、Palmyra Vision 7B。(#1652, #1646, #1707, #1712, #1724, #1709, #1755, #1704, #1795, #1832)

### 管理者向け

- Knowledge Base: より低コストなベクトルストアとして S3 Vectors を使えるようになり、ガードレールが RAG チャットの回答にも適用されるようになりました。(#1471, #1649)
- 管理者ページで、全ユーザーのトークン使用量と推定コストを、ユーザーや期間で絞り込んで確認し、CSV でダウンロードできるようになりました。Bedrock の呼び出しにユーザーとユースケースのタグが付くため、モデル呼び出しログでも利用状況を分析できます。(#1827)
- 新しいリリースが出ると、設定画面の「システム」タブで管理者にお知らせするようになりました。
- 閉域モードで、AgentCore が閉域 VPC 内で動作し、VPC エンドポイントは利用する機能の分だけ作成されるようになりました。閉域モードで使えない設定はデプロイ時に警告されます。(#1814, #1761, #1723)
- Bedrock で提供終了済み、または提供終了予定のモデルを設定している場合、デプロイ時に警告するようになりました。(#1832)
- デプロイとアップデートの手順がリリースタグを使う形になり、カスタマイズした環境に新しいリリースをマージするためのエージェントスキルを追加しました。(#1766, #1777)
- `hostName` を指定せず、ゾーンの頂点 (Zone Apex) にカスタムドメインを設定できるようになりました。(#1834)
- `allowedDevOrigins` で、手元で動かしているフロントエンドからデプロイ済みの API を呼べるようになりました。(#1808)

### アップデート前の確認事項

- **Knowledge Base の Web Crawler データソースの削除**: Bedrock で、カスタマー管理の Knowledge Base に新しく Web Crawler コネクタを作成できなくなりました。アップデートすると、既存の `web-crawler-data-source` と、そこから取り込んだドキュメントが削除されます。S3 データソースのドキュメントには影響しません。(#1747)
- **画像・動画生成のデフォルトモデル**: Nova Canvas と Nova Reel が提供終了 (EOL) になりました。画像生成のデフォルトは Stable Image Core (`us-west-2`) になり、動画生成はデフォルトで無効になりました。動画生成を続けて使う場合は、`videoGenerationModelIds` に `us-west-2` の `luma.ray-v2:0` を指定し、そのリージョンを bootstrap してください。モデルを自分で指定している環境には影響しません。(#1791)
- **テキストモデルのデフォルト**: `modelIds` を設定していない場合、`us.deepseek.r1-v1:0` (2027-03-30 に提供終了) が `openai.gpt-oss-120b-1:0` に置き換わります。`modelIds` を設定している環境には影響しません。(#1832)
- **デフォルト設定での提供終了の警告**: 画像生成のデフォルトモデル `stability.stable-image-core-v1:1` は Legacy (2027-05-09 に提供終了) のため、デフォルト設定ではデプロイ時に警告が 1 件表示されます。現時点で切り替え先となる Bedrock のテキストから画像を生成するモデルはありません。(#1832)
- **モデルの機能の修正**: Bedrock が受け付ける内容に合わせて、Mistral Large 3 と Ministral 3 で画像を添付できるようになり、Gemma 3 ではドキュメントを添付できなくなり、DeepSeek-R1 では推論の切り替えが表示されなくなりました。(#1832)
- **Knowledge Base の Advanced Parsing のデフォルトモデル**: これまでのデフォルト (Claude 3 Sonnet) が 2026-11-13 に提供終了になったため、`global.anthropic.claude-sonnet-4-6` に変わりました。(#1813)
- **閉域モード: VPC エンドポイント**: 有効にしていない機能の VPC エンドポイントは削除されます。インポートした VPC で他のワークロードが使っている場合は、デプロイ前に `closedNetworkAdditionalVpcEndpoints` に指定してください。
- **閉域モード: 検証用インスタンス**: 検証用インスタンスのタイプが `t3.large` に変わります。以前のタイプを使い続ける場合は `closedNetworkTestEnvironmentInstanceType: 'r6i.large'` を指定してください。
- **閉域モード: AgentCore**: AgentCore を有効にしている場合、ランタイムが閉域 VPC 内に移り、`agentCoreRegion` は `region` と同じである必要があります。`researchAgentEnabled` は閉域モードと併用できません。
- **閉域モード: API Gateway**: API Gateway のリソースポリシーの形が変わり、API のデプロイメントが作り直されます。許可していないエンドポイントからのリクエストは 401 ではなく 403 になります。(#1814, #1723)
- **新しい Cognito グループ**: `SystemAdminGroup` が作成されます。ユーザープールに同じ名前のグループがすでにある場合、アップデートが失敗します。(#1827)
- **設定画面**: 「システム」タブの最近の Pull Request の一覧は、デプロイしているバージョンのリリースノートに置き換わりました。リリースノートはビルド時に `docs/en/RELEASE_NOTES.md` と `docs/ja/RELEASE_NOTES.md` から読み込みます。新しいリリースのお知らせは `SystemAdminGroup` のメンバーにだけ表示され、GitHub の最新のリリースとバージョン全体を比べます。
- **議事録の文字起こし** は、UI の言語ではなく自動判別 (デフォルトは日本語と英語) で始まるようになりました。対象言語は設定画面で変更できます。(#1779)
- **`hostName` なしのカスタムドメイン**: `domainName` と `hostedZoneId` を設定し `hostName` を設定していない場合、アップデートするとゾーンの頂点 (`domainName` そのもの) の証明書と A レコードが作成されます。これまではカスタムドメインは設定されませんでした。不要な場合は `domainName` と `hostedZoneId` を削除してください。ゾーンの頂点に A レコードがすでにある場合、アップデートが失敗します。(#1834)
- **ファイルと文書の認可をサーバーで行うように**: ユーザーが開く・削除する・モデルに渡すファイルや文書を、サーバーが判定するようになりました。新しいファイルは、ファイル用バケットのユーザーごとのプレフィックス (`users/<sub>/`、`sub` は Cognito のユーザーの `sub`) に保存されます。アップデート後は次のようになります。
  - このリリースより前に保存されたファイルは、表示も入力としての利用もできなくなります。対象は、チャットの添付ファイルと画像、生成した動画、エージェント (Bedrock Agent、AgentCore、MCP チャット) が返したファイルです。過去のチャット自体は開けますが、そのファイルは開けません。
  - 共有したチャットで表示されるのは、メッセージに添付したファイル (`extraData`) だけです。本文中のリンクとして現れるだけのファイルは表示されません。
  - 引用文書をダウンロードできるのは、GenU が作成した Knowledge Base または Kendra のデータソース (データソースバケットの `docs/`) の文書だけで、Knowledge Base の文書はそのユーザーの検索フィルタで許可される場合だけです。既存の Kendra インデックスや外部の Knowledge Base の文書はダウンロードできなくなります。
  - MCP チャットはファイルを返さなくなります。
  - アップデート前に作成した共有リンクでは、チャットの持ち主がそのチャットの共有ダイアログをもう一度開くまで、新しいファイルが表示されません。
  - ファイルは Cognito ユーザープールのユーザーの `sub` に結び付きます。ユーザーを削除して作り直した場合や、ユーザープールを新しく作り直した場合は、以前のファイルに届かなくなります。特定のユーザーのファイルを探すときは、Cognito でそのユーザーの `sub` を確認し、ファイル用バケットの `users/<sub>/` を一覧してください。
  - Mermaid の図は画像として表示されます。クリック操作、図の中で指定したスタイル、改行と書式以外のラベル中の HTML は効かなくなります。
  - `GET /file/url` と `DELETE /file` のパラメータが変わりました。これらを呼び出す独自のクライアントは更新が必要です。
- **このリリースより前に保存されたファイル**: バケットには残りますが、アプリからは開けなくなります。任意で実行できるスクリプト ([`packages/cdk/scripts/migrate-user-files`](https://github.com/aws-samples/generative-ai-use-cases/tree/main/packages/cdk/scripts/migrate-user-files)) で、そのファイルを指しているチャットや動画ジョブの持ち主のプレフィックスに移し、以前の共有リンクに持ち主を記録できます。移したあとは、利用者は以前のファイルをまた開けます。スクリプトは S3 の中でコピーして元のファイルを消さず、書き換えるレコードの変更前の値を保存するので元に戻せます。持ち主を 1 人に決められないファイルは移さずにレポートに出します。まず `--apply` を付けずに実行して、レポートを確認してください。元のキーのファイルを残すか削除するかは、データの保存方針に従って判断してください。対象は、ファイル用バケット (`GenerativeAiUseCasesStack` の `APIFileBucket…`) のうちキーが `users/` で始まらないオブジェクトと、書き込まれなくなった AgentCore のファイル用バケット (`AgentCoreStack` の `AgentCoreFileBucket…`) のすべてのオブジェクトです。削除は元に戻せません。削除する前に一覧を出して内容を確認してください。

### セキュリティ

- ユーザーが開く・削除する・モデルに渡すファイルや文書を、リクエストが指定するバケットとキーではなくサーバーが判定するようになりました。[セキュリティアドバイザリ](https://github.com/aws-samples/generative-ai-use-cases/security/advisories/GHSA-ppq8-v83g-mj96) と「アップデート前の確認事項」を参照してください。

### 修正

- 長いメッセージを送ったときに会話が巻き戻らずに保存され、非常に長いテキストを貼り付けると添付ファイルになるようになりました。(#1757)
- Bedrock がリクエストを拒否した理由 (画像サイズの上限など) を表示するようになりました。(#1789, #1822)
- 同じ名前の添付ファイル、Shift_JIS / EUC-JP のドキュメント、空のテキスト、Bedrock が受け付けないファイル名の文字に対応しました。(#1756, #1805, #1679, #1765, #1801, #1677)
- Ministral 3 と Qwen3 235B が再び使えるようになりました (デフォルトの `maxTokens` がモデルの上限を超えていました)。システムプロンプトを受け付けないモデルに空のシステムプロンプトを送らなくなりました。(#1832)
- フローを設定していない場合、`/flow-chat` は「見つかりません」のページになります。(#1829)
- ブラウザのページ翻訳を使ったあとも正しく動くようになりました。(#1828, #1833)
- S3 Vectors の Knowledge Base で、`{{retrieveKnowledgeBase}}` を使うユースケースが動くようになりました。(#1837)
- エージェントギャラリーの同期、IP 制限を設定していない場合の S3 の権限、長い会話の読み込みを修正しました。(#1826)
- 大きな画像は添付時に長辺 2,576 px に縮小し、画像の縦横で Bedrock に拒否されないようになりました。画像を 20 枚まで受け付けないモデルでは添付できる枚数を制限します (Llama 3.2 Vision は 1 枚、Llama 4 は 8 枚)。(#1835, #1836)
- 議事録: リアルタイムの文字起こしが意図せず止まったときに再接続し、音声のサンプルレートを Transcribe に送るようになりました。(#1645, #1758)
- 新しい Claude モデルが受け付けないアシスタントのプレフィルを、文章生成と続きの生成で送らなくなりました。Claude Fable 5、5.1、5.2 にプロンプトキャッシュが効くようになりました。(#1705, #1851, #1839)
- 動画生成で、完了した動画が再びコピーされるようになりました。(#1790)
- 送信できないほど大きなメッセージでも添付ファイルが残り、チャットで前に添付したドキュメントも上限に数えるようになりました。(#1800, #1810)
